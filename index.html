One phone. Two PINs. A Guest mode that can't wander off-list.

YPVM splits a single Android device into your full, unrestricted Host environment and a separate Guest environment that can only open apps you've whitelisted — for parents setting up a kid's device, or anyone lending their own phone out for a while.

Features

Built on Android's own APIs, not a workaround

Dual-PIN lock screen

One PIN opens Host, the other opens Guest — no menu to fumble through in front of the person you handed the phone to.

App whitelist

Guest's Work Profile can only launch apps explicitly allowed by whoever set up Host.

Visible Emergency Unlock

A clearly-labeled control that returns to Host from Guest mode — see Security for why it's visible on purpose.

Crash-resilient watchdog

A boot receiver and relaunch service keep the lock screen enforced even after a crash or reboot.

Keystore-backed PINs

Both PINs are stored via Android Keystore with lockout after repeated failures.

Device Owner provisioning

Set up fresh via dpm set-device-owner before any account is signed in — no MDM subscription required.

Security

What was deliberately left out — and why

Two capabilities that would have made Guest mode harder to notice were considered and rejected. Both are explained in full in the repo's ARCHITECTURE.md.

Design decisions

NOT BUILT

A hidden or invisible gesture to silently return to Host from within Guest mode.

NOT BUILT

Any method to defeat a Host-authenticated ADB session from inside Guest mode.

BUILT INSTEAD

A visible, clearly-labeled Emergency Unlock control. It does the same job — returning control to Host — with identical security, without requiring the person using Guest mode to be kept unaware that a privileged mode exists on their own phone.

Architecture

Where the boundary actually lives

app/src/main/java/com/mnmyounus/ypvm/ ├── admin/ Device Owner + Work Profile policy logic ├── watchdog/ Crash-resilient relaunch service + boot receiver ├── security/ Keystore-backed PIN storage and lockout └── ui/ Lock screen, Guest launcher, Emergency Unlock

Build & install as Device Owner

./gradlew assembleDebug # APK in app/build/outputs/apk/debug/ ./gradlew installDebug adb shell dpm set-device-owner \ com.mnmyounus.ypvm.debug/com.mnmyounus.ypvm.admin.YpvmDeviceAdminReceiver

Device Owner status requires no Google account be signed in yet — this works cleanly on a factory-reset device or a fresh emulator. Full first-run walkthrough (both PINs, provisioning Guest, choosing the whitelist) is in ARCHITECTURE.md §8.

FAQ

Common questions

Can the Guest-mode user tell a Host mode exists?

Yes — that's intentional. The Emergency Unlock control is visible, not hidden. See Security for the reasoning.

Does this need an MDM subscription?

No. It uses Android's own Device Owner / Work Profile APIs directly — no third-party mobile device management service involved.

What if Android Studio offers an AGP upgrade?

Safe to accept. This repo pins a known-stable toolchain for reliable first builds, but nothing depends on deprecated APIs.
